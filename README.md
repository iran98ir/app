# Vista App

اپلیکیشن اندروید **مشاوره آنلاین**

---

## 📱 مشخصات

| ویژگی | مقدار |
|---|---|
| Package | `app.vista` |
| نام نمایشی | مشاوره آنلاین |
| حداقل اندروید | 6.0 (API 23) |
| هدف | Android 15 (API 35) |
| زبان | Java |
| ساخت | GitHub Actions |

---

## 🎨 طراحی

- **Splash Screen** با لوگو و انیمیشن نرم
- **لود پس‌زمینه** سایت در حین نمایش Splash
- **WebView تمام‌صفحه** بدون address bar
- **تشخیص هوشمند لینک** (داخلی/خارجی)
- **Back Button هوشمند** با دیالوگ خروج
- **صفحه‌ی آفلاین** و **صفحه‌ی خطا**
- **Progress Bar** نازک بالای صفحه
- **Dark Mode** خودکار
- **Safe Area** برای ناوبار مجازی
- **Cache قوی** برای لود فوری

---

## 🚀 ساخت APK

هر بار که کد رو تغییر بدی و پوش کنی، GitHub Actions خودکار APK می‌سازه.

### مراحل:

1. برو به تب **Actions** توی ریپازیتوری
2. آخرین workflow run رو انتخاب کن
3. توی بخش **Artifacts** فایل `app-debug` یا `app-release` رو دانلود کن
4. APK رو روی گوشی نصب کن

### لینک مستقیم:

`https://github.com/iran98ir/app/actions`
